# Prototip (tasarım/iş kuralı referansı)

Bu klasördeki `tera-portal-prototip.html`, sunucusuz, tek dosyalık bir arayüz/iş kuralı
demosudur. Sahte veriyle bellek içinde çalışır; gerçek bir API'ye bağlı değildir.

**Üretim kodu bu değildir.** Gerçek, API'ye bağlı arayüz `client/`, gerçek sunucu
`server/` altındadır. Kurulum için `docs/KURULUM.md` dosyasını kullanın.

Bu prototip, henüz `server/`+`client/` tarafına taşınmamış tasarımları (Toplantı Notları,
Gantt Chart, Admin Panel > SMTP Ayarları, duyarlı/mobil düzen) içerir — bkz.
`docs/HAZIRLIK-DURUMU.md` bölüm 5.
